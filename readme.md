For running a singleplayer game:
1. open the terminal
2. Go to the Local_TEJ4M_BATTLESHIP directory (or the name of the current working directory)
3. type "python3 game_singleplayer.py"

For running a mulitplayer game:
1. open the terminal
2. Go to the Local_TEJ4M_BATTLESHIP directory (or the name of the current working directory)
3. type "python3 game_multiplayer.py"

Note:
If you wish to test out the AI or make any modifications, please first test it within AI.py before continuing and implementing it in "game_singleplayer.py". 
Or you can test, implement and then download the source files again XD
